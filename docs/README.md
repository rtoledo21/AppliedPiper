# Documentation

This folder is the project's running explanation of itself — not user
instructions (that's the root `README.md`), but *why* the code is shaped
the way it is.

- **architecture.md** — how the pieces fit together right now. Updated as
  new modules are added.
- **decisions/** — Architecture Decision Records (ADRs): one file per
  significant design choice, each explaining the context, the decision,
  and its consequences. Written once and never edited after the fact —
  if a decision changes later, a new ADR supersedes the old one rather
  than rewriting history. This follows the lightweight ADR format
  popularized by Michael Nygard, widely used across the industry as a
  way to preserve *why* alongside *what*.
